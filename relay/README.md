# PlexonPanel relay

This Cloudflare Worker is a real-time coordination relay, not a telemetry
database. One `ServerRoom` Durable Object is selected by the plugin's persistent
server UUID. A single `PairingDirectory` stores short-lived HMAC pairing lookups
and HMAC address-rate state.

Durable storage is limited to:

- the plugin's public identity, versions, and capability flags
- paired state and a revocation generation
- the current five-minute pairing registration
- pairing-attempt counters for a fifteen-minute window

Telemetry, console lines, chat, and action results are sent to currently
authorized browsers without being written to Durable Object storage. The relay
can inspect frames in memory after TLS termination, so the design is signed and
non-persistent rather than end-to-end encrypted.

## Local build and test

```bash
npm run relay:build
npm run relay:test
```

Generate a development/deployment identity once:

```bash
npm run relay:keygen
```

The command creates protected, ignored `.dev.vars`, `.relay-secrets.json`, and
`.relay-public.json` files and prints no key material. `.dev.vars` is consumed
by local Wrangler. `.relay-secrets.json` is suitable for `wrangler secret bulk`.
The public file contains the key that the Paper plugin must pin.

## Local relay

Keep `DASHBOARD_ORIGINS` set to `http://localhost:3000`, then run:

```bash
npm run relay:dev
```

Set the dashboard's `NEXT_PUBLIC_PLEXON_RELAY_URL` to the HTTPS/loopback origin
Wrangler displays. Configure the Paper plugin with the corresponding
`ws://127.0.0.1.../v1/agent` loopback URL and public key.

## Cloudflare deployment

1. Set `DASHBOARD_ORIGINS` in `wrangler.jsonc` to exact comma-separated Vercel
   origins. Wildcards are deliberately unsupported.
2. Run `npx wrangler@latest login`.
3. Run `npx wrangler@latest deploy --config relay/wrangler.jsonc`.
4. Run `npx wrangler@latest secret bulk relay/.relay-secrets.json --config relay/wrangler.jsonc`.
5. Run the deploy command again and verify `/healthz`.

The Worker requires four bindings generated by the key tool:

```text
PAIRING_CODE_PEPPER
ACCESS_TOKEN_SECRET
GATEWAY_ED25519_PRIVATE_KEY
GATEWAY_ED25519_PUBLIC_KEY
```

Never commit `.dev.vars`, `.relay-secrets.json`, the relay private key, the
access-token secret, or the pairing pepper. Key rotation invalidates the
plugin's pinned relay identity and must be coordinated deliberately.
