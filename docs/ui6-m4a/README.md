Set `PLEXON_CHROMIUM_EXECUTABLE`/`LD_LIBRARY_PATH` for the local headless-shell environment. Run batches sequentially; each runner owns its localhost fixture/app server. `UI6_TASK=metrics` executes inspection/CPU/CLS measurements; `scripts/verify-ui6-foundation.mjs` owns dev foundation or production font checks. No production deployment or credentials are used.
