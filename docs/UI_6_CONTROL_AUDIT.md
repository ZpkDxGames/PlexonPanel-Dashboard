## Shared authorization boundary

For any `can(A,K)` or `run(A,P,K)`: verified session grant intersects relay ready grant; Protocol/action contract and target compatibility must match; target agent must be connected; canonical action scope and agent capability must be present. Browser cannot separately prove undisclosed agent policy: unavailable policy is unknown, agent denial authoritative. `run` rechecks authorization after confirmation and captures immutable server/socket/agent generation; uncertain completion is not retried. Read-only `useQuery` uses existing signed channel and the caller’s enabled gate. Local controls never acquire extra authority.
