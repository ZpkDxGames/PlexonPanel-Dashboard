## Separate owner authorization — not granted by this package

- [ ] Owner reviewed concrete PR/evidence and explicitly authorized merge.
- [ ] Owner separately authorized the intended production release/promotion, exact origin and runtime acceptance scope.
- [ ] Previous immutable frontend artifact/ref available on the same origin; stored pairings preserved.
- [ ] Real runtime tests use exact paired instance/agent/version and authorized safe fixtures/backups; outcomes recorded individually.
- [ ] No hidden VPS/relay/Host/Paper/provider/credential changes are bundled into a visual release.

Do not mark these boxes from source inspection, a successful preview build or a fixture screenshot. Production rollout is a later task.

## Implementation final-response template

Provide: PR URL or blocker; base/head/backend SHAs; selected concept and visible changes by route; test/performance result summary; screenshot/evidence links; parity and known limitations; rollback location; explicit “not merged or deployed; production requires separate owner authorization.” Do not claim universal 60fps, real 24h soak, live backup integrity or physical-device compatibility without the corresponding executed evidence.
