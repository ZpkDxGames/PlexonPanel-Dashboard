# Deferred backend work

No backend extension is implemented or represented as an active control. Browser restores, recovery-journal clearing, scheduled backups, provider credentials, server file editing/upload, player inventory/ender chest/notes, unsupported lifetime statistics and new skin-proxy deployment remain outside this change.

The query abstraction currently reduces failed Host reads to errors. The route displays the returned error text and Unknown checks; it does not reconstruct structured failure stages from arbitrary messages. Successful preflight fields are displayed only when Host actually returns them. A future structured-error extension needs its own protocol/adapter review.

Physical-device keyboard behavior, assistive-technology acceptance and real paired VPS/agent/provider certification require separately scoped acceptance. Local fixtures do not certify live archive integrity or running server versions.
