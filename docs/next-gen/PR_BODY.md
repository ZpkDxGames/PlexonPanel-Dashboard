# Implement Strata across all eight PlexonPanel workspaces

The current Control Room frame spreads source evidence and operational workflows across disconnected surfaces. Strata rebuilds the complete eight-route frontend around a horizontal workspace frame, connected reading strips and ledgers, and explicit Paper/JVM/service/node evidence. It also fixes provider-error reset, terminal resize/tail behavior, partial backup-read presentation and the inherited skip-link route change.

- Fleet and Overview gain connected instance/resource ledgers and a first-viewport instrument/console composition. Performance preserves all eight signals with a focus catalog, fixed inspection shelf, exact capture pinning and comparison tracks.
- Players preserves exact-UUID history and every action family across Interact/Moderate/Commands. Console measures row/viewport geometry, distinguishes following from inspecting, and preserves Chat, Plugins and reviewed Paper commands.
- Backups puts durable Host proof/error/retry before inventory, distinguishes independent read failures and expired readiness, and reports accepted QUEUED jobs separately from completion. Access keeps Host/Paper audit isolation, current-browser protection and an immutable effective-authority ledger.
- Settings retains all four section links and eight preference fields with truthful browser-application feedback. Pairing, navigation, review focus and both themes/narrow layouts use the same presentation system.

Protocol 3, IndexedDB pairing, scoped fail-closed authority, prepared exact targets, raw source clocks/epochs, manual Host backups and every retention limit are unchanged. No protected adapter/lib/preference parser, backend/VPS/relay, credential or dependency/lockfile change is included. The sole configuration change is the owner-approved Vercel no-deploy guard for this exact feature branch.
