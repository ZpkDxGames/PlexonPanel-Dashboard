# Build plan

Follow the binding specification's section 13 in order, with a green checkpoint commit per phase:

1. Discovery and architecture.
2. Foundation and adapter compatibility.
3. Data layer and truthful development fixtures.
4. Fleet, Overview and Performance; rendered design inspection and correction.
5. Players, skins, bound actions, commands and negotiated permission tiers.
6. Safe ANSI/legacy/MiniMessage parser, virtualized Console and Chat.
7. Backups, Plugins, Access & Audit and Settings. Configuration is intentionally omitted by user direction.
8. Motion, responsive, accessibility and performance polish.
9. Verification evidence and required documents.
10. Separate preview and factual completion report.
