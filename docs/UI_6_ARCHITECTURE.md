# UI 6 architecture through M4a

This document describes implemented ownership. Overview and Tick Pulse are implemented and validated for M4a review; final check is green. The dense whole-page long-task gate failed, so the milestone is not fully green. Fleet and Performance rebuilding remains outside the authorized scope.

`navigate` checks the dirty editor before changing workspace and cancels any unconfirmed operation. `switchServer` checks the same guard, cancels confirmation, advances the selection revision, retires the old command socket synchronously and clears displayed state before storage can yield. Same-instance workspace navigation retains the signed live connection. An already dispatched result still belongs to its original instance/generation; it cannot leak into another instance. These are inherited behaviors characterized before extraction.

The metadata tray observes connection snapshots, validated operation completions and the existing Backups view's matched durable job/phase. It copies canonical action names, authority, allowlisted result codes, supplied phase keys, server/job IDs and a browser-observed timestamp. Unknown result messages and parameter objects are dropped. Repeated completions remain distinct; unchanged source snapshots deduplicate. Clearing the tray affects this tab only. It is separate from the existing server audit and bounded chat cache.

Workspace mounting can issue its existing authorized **read requests**, such as file inventory or console history. The palette itself does not execute an action; mounted integration tests forbid mutating requests across every destination. Existing bound action tests retain the actual signed two-room relay flow, revocation, grant intersection, lifecycle BUSY handling, dirty leave and file conflict preservation.

The native drawer opens below 1024 CSS px, makes the shell frame inert, traps Tab/Shift+Tab and restores focus. Native popovers keep their controlled target in the DOM while closed. Axe's incomplete checks for these references and floating/SVG text are supplemented with actual DOM-reference/expanded-state checks and measured opaque rendered colors. These checks do not claim screen-reader or cross-browser certification.

The compact Pulse is loaded only after the existing shell-paint gate. Root advances a shared browser-time window end only on a changed selected instance or Paper capture; the existing chart-window preference supplies 1/5/15/30 minutes. Shared age-clock ticks and Host-only samples do not advance or redraw the raster, including when a previously future Paper timestamp becomes past or Host traffic prunes retention. The raster is a derived snapshot at its labelled window end; the exact table uses the currently retained captures. Disconnect metadata does not advance that window. New captures update it; initial mount and explicit size/window/theme changes require a repaint. Resize observation is disconnected on unmount. DPR is capped at two; summary buckets and hatch work are bounded by plot pixels. Exact table/lens keeps every retained, valid, nonfuture Paper capture, including those outside the visible time window. The table mounts only on inspection and contains at most 100 rows. No smoothing, interpolation, averaging or count-up animation is present. The M2 model is unchanged. Version labels remain 5.0.0 until the coordinated version/documentation milestone.

Full/header instances share Paper observation normalization through a private WeakMap keyed by the existing immutable bounded history arrays. Weak keys do not create a second retention/persistence owner. Canvas diagnostic measures are capped at 200 entries. Inline sparklines use the existing metric-report helpers over a source-qualified five-minute snapshot, with an accessible labelled end time. The optional original TPS/MSPT charts mount only while their disclosure is open. Ordinary connecting/online status on Overview remains in status semantics rather than a collapsing visible banner; substantive error/stale/disconnected banners remain visible. Header/plot geometry is reserved across hydration. The dev-only gallery is browser-rendered with deterministic specimen windows to avoid SSR fixture-time mismatches and remains excluded by the production compound-extension rule.
