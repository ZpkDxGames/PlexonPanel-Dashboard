## Cross-cutting gaps

- No per-workspace React error boundaries/recover UI. Several initial states use generic empty copy instead of shaped loading placeholders.
- Busy ActionButton behavior exists, but local result persistence is inconsistent; a single shell notice can be overwritten by read queries. No session-only operational activity tray today.
- `can` returns a boolean; generic failure combines permission/local policy. The browser cannot distinguish an undisclosed policy denial from missing capability without an actual response. New disabled explanations must preserve that uncertainty.
- Inventory capture age and retained-query refresh age are not consistently disclosed. Agent connection, source capture and receipt clocks must remain separate in the redesign.
- The shell restart gate has the approved missing-Host-state defect. Server itself already preserves unknown. M3 must prove all callers agree without changing the signed service contract.
- Existing legacy roster History controls remain in source but production mounts showHistoryTab=false; modal is the active retained-history surface. Do not count hidden branches as user-visible parity features.
