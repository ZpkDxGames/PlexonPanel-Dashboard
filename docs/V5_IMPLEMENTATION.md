# PlexonPanel 5.0 implementation

The legacy visual tree, planning reports, proof scripts and Vite hosting metadata are removed. Presentation lives under src/ui; App Router serves all eight workspaces, pairing and development proof galleries. Root AGENTS.md and SKILL.md are installed verbatim. Git-triggered deployment is disabled; CI verifies only. The nonce CSP lives in proxy.ts and allowlists the existing relay HTTP/WS origin.

The original eight preferences, signing, scope mappings, grant reconciliation, action preparation and mutation execution are retained. Four adapter files contain targeted v5 changes: browser-store removes and migrates control caches; control-state ingests real percentile fields and boot resets without persisting logs and exports the existing console identity helper; maintenance accepts schema-v2 opt-in schedules; session preserves Host-epoch boundaries and serializes differing read parameters through its existing per-action execution lock. Query serialization fixes concurrent console/chat backfill without changing reason, prepare or execute.

UI projections mask revoked scopes immediately. Authority, target and boot changes remount volatile route buffers. Console row keys use journal cursors, stream session/sequence, then deterministic legacy identity. Both Host console and standard chat are cursor-paginated with chronological, bounded volatile windows (2,500 console lines / 500 chat messages). Historical browsing excludes live arrivals until the user returns to live. Console and chat timestamps follow the selected timezone. No console, chat, command history or control cache enters browser persistence.

Real wire fields include maximumPlayers, p95TickMillis, p99TickMillis, pingMillis, processUptimeMillis and bytesUploaded. Paper supplies p99 from its actual tick window, not percentiles of telemetry averages. The detail histogram explicitly counts mean samples. GC markers use capture-local counter deltas. Longer range controls show only the available 35-minute/8,192-point bounded history. Each series retains its own source clock and epoch gaps. Memory tiers overlap rather than falsely adding heap and cgroup totals. Service values require authoritative MINECRAFT_SERVICE/SYSTEMD_CGROUP metadata.

Host stage definitions refine coarser durable phases; they are not additional recovery checkpoints. Retry Upload follows Host permission. Missing hashes, historical per-player ping, tick-wait and actual relay round-trip latency remain unreported. Relay bars indicate connectivity. Standard journal chat history requires both full-console and chat scopes; custom plugin chat formats remain live-only. The local OTP entry timer does not override relay-enforced expiry.

Semantic/muted text tones are adjusted for AA contrast; exact accent triplets are preserved. Mobile retains trend/percentile pills, command scopes, gradients and all instrument visualizations. Skeleton wells carry loading layouts. Motion off/reduced includes pseudo-elements and springs. Mutating controls use ActionReview and show disabled reasons.

Build with Node 24: npm ci; npm run typecheck; npm run lint; npm test; npm run build; npm start. Use CHROME_PATH or install Playwright Chromium to run scripts/v5-browser.mjs. scripts/v5-production.mjs tests the built application. Backend migration, native-library packaging and live certification limits are documented in the matched backend source. This handoff performs no deployment or live server operation.
