# Design lock: Signal Atlas

Two desktop/mobile coded concept proofs: Signal Atlas (ink/lavender instruments with fixed rail) and Terrain Register (cream/forest editorial horizontal ledger). Atlas selected for faster persistent navigation and richer live instrumentation. Schematic concept strokes are labelled and never used as product data.

The new structure uses a compact labelled rail, server breadcrumb, separate Paper/Host provenance ribbon, numbered workspace titles, instrument canvases and open metric ledgers. Overview prioritizes separate TPS/MSPT tracks; Performance is a unit-aligned diagnostics lab; Fleet is grouped server topology; Console is a terminal workstation; Backups is an ordered operation journal; Access is a device/grant register; Settings uses focused sections. Each route has a different composition.

Warm ink rather than navy; lavender signal, ice secondary, restrained semantic green/amber/red. Light mode uses neutral limestone and white instrument sheets with independent contrast colors. Local Manrope and JetBrains Mono retained for legible headings and tabular measures. Four/eight spacing, 44px controls, 12/16px metadata/body, 32–40px key metrics. No scale transforms for responsive layout.

Micro-feedback 140ms, route reveal 220ms, single-load instrument reveal 500ms. CSS respects OS reduction and user reduced/off; no streaming numeric animations. Mobile uses a full navigation drawer, stacked instruments and reachable controls. Crosshair, pin, arrow navigation, truthful table and provenance details are part of the chart anatomy.

Visual review covers all routes in dark/light at 1440px and 390px, plus the original expanded matrix. The initial concept and comparison screenshots are development-only synthetic data. The working product contains no schematic production metrics. Small footer/axis typography was increased following actual screenshot review. Mobile roster selection scrolls deliberately to the selected profile; terminal output remains locally scrollable rather than expanding the viewport.
