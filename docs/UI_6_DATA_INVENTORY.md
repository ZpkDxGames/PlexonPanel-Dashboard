## Adapter rules and reserved distinctions

`metric-reports` provides per-source series, min/avg/sample p95/max, actual sample count, observed coverage and export of ten metrics (nine displayed charts plus GC). Gap separation uses at least1s or3×source interval. Freshness: waiting/missing, future capture beyond5s, delayed beyond10s, stale beyond30s, otherwise live; thresholds are the existing adapter’s behavior, not guessed polling health. Chart geometry is native bounded SVG with at most800 retained points per segment; no smoothing across missing intervals. Browser windows1/5/15/30 minutes only.

The catalogue includes local UI props, helper objects, DOM and imported type members; those are not signed backend fields. `lib/management-data.ts` is not a packet authority and its unused legacy interfaces must not become design capabilities. `lib/cpu-load.js` is not consumed by these workspaces and may be removed only in approved M8. The saved preferences list is19 controls/fields, not a new settings schema; density/text/motion/charts/display cadence remain existing state owners.
